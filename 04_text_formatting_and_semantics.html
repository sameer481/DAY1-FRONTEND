Text Formatting & Semantic Elements

Why semantic markup matters: Writing accessible, screen-reader friendly typography.

1. Semantic vs. Presentational Tags

In early HTML, tags like <b> and <i> were used purely for physical styling. Modern HTML5 emphasizes semantics: choosing elements based on the meaning of the content, not how it appears on screen.

Semantic Element Presentational Equivalent Semantic Purpose / Meaning
<strong> <b> Indicates strong importance, seriousness, or urgency (read with emphasis by screen readers).
<em> <i> Stress emphasis that changes the phonetic inflection and meaning of a sentence.
<mark> None Highlights text of current relevance or search result matches.
<small> None Side-comments, fine print, copyright statements, and legal disclaimers.
<del> & <ins> <s> & <u> Represents tracked edits: deleted text and newly inserted replacement text.
<sub> & <sup> None Subscripts (chemical formulas like H2O) and Superscripts (exponents like x2).

3. Quotations, Abbreviations & Technical Terms

The <abbr> element defines an abbreviation. Hovering displays the expanded title:

The W3C develops open web standards for HTML and CSS.

Long quotations belong inside <blockquote> with an optional <cite>:

"Any application that can be written in JavaScript, will eventually be written in JavaScript." — Jeff Atwood (Atwood's Law)

Inline short quote with automatic quotation marks using <q>:

Tim Berners-Lee famously said, The power of the Web is in its universality.
