Headings, Paragraphs & Text Hierarchy

Structuring text content for readability, accessibility, and SEO ranking.

1. Heading Hierarchy (h1 to h6)

HTML offers six levels of section headings from <h1> (most important) down to <h6> (least important). Headings are block-level elements that establish the structural outline of a webpage.

<h1>Level 1 Heading - Main Document Title</h1> <h2>Level 2 Heading - Major Section</h2> <h3>Level 3 Heading - Sub-section</h3> <h4>Level 4 Heading - Deep Sub-topic</h4> <h5>Level 5 Heading - Minor Sub-topic</h5> <h6>Level 6 Heading - Least Prominent Heading</h6>

CRITICAL SEO & ACCESSIBILITY RULE: Never use more than one <h1> per webpage! The <h1> represents the single overarching subject of the page. Do NOT skip heading levels (e.g., jumping from <h2> straight to <h4>) because screen reader users rely on headings to navigate.

2. Paragraphs (<p>)

The <p> element represents a paragraph of text. Browsers automatically add vertical margin before and after every paragraph to separate blocks of text cleanly.

<p>Frontend engineering begins with understanding the document tree.</p> <p>HTML delivers meaning and structure, while CSS delivers presentation.</p>

3. Line Break (<br>) vs. Horizontal Rule (<hr>)

Both <br> and <hr> are self-closing void elements.

  • <br>: Inserts a simple line break without creating a new paragraph block. Use sparingly (e.g. for postal addresses or poetry).
  • <hr>: Represents a thematic break between paragraph-level topics (rendered as a horizontal line).
<!-- Postal Address Example with <br> --> <p> 123 Web Dev Avenue<br> Silicon Valley, CA 94025<br> United States </p> <!-- Thematic Break with <hr> --> <hr> <p>A fresh topic begins here after the horizontal rule.</p>

Best Practice: Never use <br><br><br> to create visual spacing between sections! Always use CSS margins and padding instead.

4. Preformatted Text (<pre>)

The <pre> tag displays text in a fixed-width (monospace) font and strictly preserves both spaces and line breaks exactly as typed in the source code.
