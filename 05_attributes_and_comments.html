HTML Attributes & Comments

Supercharging HTML elements with properties, values, behaviors, and clean documentation.

1. Anatomy of an HTML Attribute

Attributes provide additional information or configure the behavior of HTML elements. They are always specified in the opening tag and usually come in name="value" pairs.

<a href="https://github.com" target="_blank" title="Visit GitHub">GitHub</a>
<!--   ↑ Attribute Name="Value"   ↑ Another Attribute     ↑ Tooltip Attribute -->

2. Essential Global Attributes

Global attributes can be used on any valid HTML5 element:

id

Unique identifier. Must be completely unique across the entire HTML document. Used for CSS styling (#id) and anchor links.

class

Reusable styling hook. Multiple elements can share the same class, and one element can possess multiple classes separated by spaces.

title

Advisory information displayed as a native browser tooltip when the user hovers over the element.

lang & dir

Specifies the language code (e.g. lang="es") and text direction (dir="ltr" for English, dir="rtl" for Arabic/Hebrew).

3. Boolean Attributes

Boolean attributes represent true/false states. If the attribute is present on the element, its value is true; if absent, it is false. Writing disabled is identical to disabled="disabled".

<input type="text" placeholder="Active input">
<input type="text" placeholder="Disabled input" disabled>

4. Custom Data Attributes (data-*)

HTML5 permits storing private custom data on standard HTML elements using the data-* prefix. This is heavily used by JavaScript and modern frameworks.

<div class="user-card" data-user-id="1048" data-role="admin" data-active="true">
  Sameer Mohammed
</div>

5. Commenting Best Practices & Security

Comments allow teams to document structure and temporarily isolate bugs. Always follow professional conventions:

<!-- ========================================== -->
<!-- SECTION: MAIN HERO BANNER -->
<!-- ========================================== -->
<section id="hero">
  <h1>Frontend Mastery</h1>
</section>
<!-- /#hero -->
SECURITY WARNING: HTML comments are completely readable by anyone who views the page source or inspects elements. Never store passwords, internal IP addresses, API secrets, or confidential business notes in HTML comments!
