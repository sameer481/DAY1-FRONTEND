Introduction to HTML & Syntax

Understanding HyperText Markup Language, Elements, Tags, Nesting, and Comments

1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used by web browsers worldwide to structure and display content on the World Wide Web.

  • HyperText: Text containing links to other texts or multimedia files.
  • Markup: Special symbols and tags annotating raw text to instruct browsers on formatting and structure.
  • Language: A standardized syntactic system agreed upon by the W3C and WHATWG consortiums.
Important Fact

HTML is NOT a programming language! It has no variables, loops, conditionals, or computational logic. It is a declarative structural markup language.

2. Anatomy of an HTML Element

An HTML element is generally composed of three primary parts: an opening tag, the inner content, and a closing tag.

<p>Hello, World! Welcome to Web Development.</p>
<!-- ↑ Opening Tag   ↑ Content          ↑ Closing Tag -->
  • Opening Tag: Tells the browser where the element begins (e.g., <p>, <h1>).
  • Content: The actual text or nested elements rendered to the user.
  • Closing Tag: Tells the browser where the element ends. Always marked by a forward slash (</p>).

3. Void (Self-Closing) Elements

Some elements do not have inner content or closing tags. These are called void elements (or self-closing elements). They describe standalone items.

<hr> <!-- Horizontal thematic break line -->
<br> <!-- Line break / newline -->
<img src="photo.jpg" alt="A mountain"> <!-- Image embed -->
<input type="text" placeholder="Type here..."> <!-- Text field -->

Note: In modern HTML5, writing <br> is preferred over the older XHTML style <br />.

4. Element Nesting & Hierarchy

HTML elements can be placed inside other elements. This is known as nesting. Properly nested elements create a clean parent-child hierarchy forming the DOM Tree.

<!-- CORRECT NESTING: Last opened, first closed (LIFO) -->
<p>This text is <strong>very important</strong> for learners.</p>

<!-- INCORRECT NESTING (WRONG! Overlapping tags): -->
<p>This text is <strong>badly nested.</p></strong>

5. Whitespace Collapsing

HTML browsers automatically collapse multiple consecutive spaces, tabs, and newlines into a single space.

<p>
    Hello   World!
    Multiple  lines  here.
</p>
Live Preview (Browser collapses extra whitespace)

Hello World! Multiple lines here.

To preserve exact spacing and newlines, use the <pre> element (Preformatted text).

6. HTML Comments

Comments are notes left in the source code for developers. Web browsers completely ignore comments during rendering.

<!-- This is a single-line HTML comment -->

<!--
    This is a multi-line HTML comment.
    Useful for leaving documentation notes or
    temporarily disabling code blocks during testing.
-->
Security Warning

Never put sensitive information (passwords, private API keys, client data) inside HTML comments! Anyone can right-click the page and select "View Page Source" to read your comments.
